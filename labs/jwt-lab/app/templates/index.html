TokenForge

A JWT exploitation lab. Three challenges, three common vulnerabilities. No libraries — raw HMAC.

1

Algorithm Confusion — alg:none

The server trusts whatever algorithm the JWT header declares. Can you get admin access without knowing the secret?

alg:none header tampering CVE-2015-9235
2

Weak Secret — Crack the Signature

Algorithm enforcement is correct. But the HMAC key is weak enough to brute-force. Crack it, forge an admin token.

weak secret hashcat john
3

Key ID Injection — kid Header SQLi

The server uses the JWT kid header to look up the signing key from a database — without parameterising the query. Inject, control the key, forge a token.

kid header SQL injection key confusion
Setup: Log in as alice / hunter2 to get a valid token, then manipulate it to gain admin access. The JWT decoder is available to inspect any token.
