# NovaMetrics

A small company website. About, Services, Careers, Contact.

```sh
pip install flask
cd app
python3 app.py
```

Visit `http://127.0.0.1:5004/`.

## Challenge

6 flags are hidden somewhere, each in the format `FLAG{...}`. None of
them require exploiting anything — this one's pure reconnaissance, not
exploitation. If you can't find all 6 using nothing but recon technique
(no guessing, no brute-forcing random strings), you have a gap to close
before tomorrow.

That's it. No further hints.

## How this was built

Built by Claude (Anthropic), on my instructions — every page, every
flag placement. I designed what it needed to test and confirmed all 6
flags myself, end to end, before using it. Built specifically as recon
practice the night before an internship viva on the subject — pure
information-gathering, deliberately free of any actual exploitation,
because that's not what was being tested.
